# Onigiri Check 🍙

เว็บไซต์ภาษาไทยที่ช่วยให้ผู้ใช้ทบทวนเหตุการณ์ที่อาจมีความเสี่ยงต่อการตั้งครรภ์ และเข้าใจเวลาที่เหมาะสมในการตรวจครรภ์

## เปิดเว็บไซต์ด้วย GitHub Pages
1. เปิด **Settings** ของ repository
2. เลือก **Pages**
3. ใน **Build and deployment** เลือก **Deploy from a branch**
4. เลือก branch `main` และ folder `/(root)` แล้วกด **Save**
5. รอให้ GitHub Pages เผยแพร่เว็บไซต์ แล้วเปิด URL ที่แสดงในหน้า Pages

## ไฟล์
- `index.html` — แบบประเมินและคำแนะนำ
- `sources.html` — แหล่งข้อมูลทางการแพทย์และคำชี้แจงความเป็นส่วนตัว

## ความเป็นส่วนตัว
แบบฟอร์มทำงานในเบราว์เซอร์ ไม่มีฐานข้อมูล ไม่มีการส่งคำตอบไปยังเซิร์ฟเวอร์ของเว็บไซต์ ไม่มี localStorage/cookies หรือ analytics ในโค้ดนี้ โฮสต์อาจบันทึกข้อมูลทางเทคนิคตามนโยบายของผู้ให้บริการ

## ข้อจำกัด
เว็บไซต์ให้ข้อมูลทั่วไป ไม่ใช่เครื่องมือวินิจฉัยทางการแพทย์ ไม่คำนวณเปอร์เซ็นต์ความเสี่ยงจากอาการ และแนะนำให้ขอความช่วยเหลือทางการแพทย์เมื่อมีสัญญาณเตือน
